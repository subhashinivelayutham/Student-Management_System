# Student Management System

## About the Project
A simple Student Management System developed using C++. It allows users to manage student records easily.

## Features
- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student

## Technologies Used
- Programming Language: C++
- Concept: File Handling

## How to Run
1. Open the C++ source file.
2. Compile the program.
3. Run the program.
4. Select an option from the menu.
